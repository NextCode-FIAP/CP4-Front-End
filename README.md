# Checkpoint 4 - Front End: Grid Layout & Responsividade

Este repositório contém o código do Checkpoint 4 (CP4) de Front-End, desenvolvido para a execução do Checkpoint 4 de Front End em Engenharia de Software na FIAP. O projeto consiste em uma página web responsiva construída exclusivamente com HTML5 e CSS3, com foco no uso  de CSS Grid.

## 🎯 Objetivo do Projeto
Desenvolver duas seções baseadas em um protótipo de design utilizando obrigatoriamente a propriedade Grid do CSS, garantindo que o layout se adapte perfeitamente a diferentes tamanhos de tela sem o uso de frameworks externos ou bibliotecas.

## 🛠️ Tecnologias Utilizadas
- **HTML5** (Semântico)
- **CSS3** (Variáveis, CSS Grid, Media Queries, Transições)

## ✨ Funcionalidades e Requisitos Atendidos
- **Grid Areas:** Utilização de `grid-template-areas` para organizar a seção principal (imagem Hero, bloco de texto explicativo e galeria de fotos de apoio).
- **Grid Responsivo Nativo:** Aplicação de `minmax()` e `auto-fit` na segunda seção (galeria do mar) para adaptação fluida e automática dos itens.
- **Responsividade (Media Queries):** Implementação de breakpoints para telas Desktop (acima de 1024px) e Mobile (abaixo de 600px), garantindo a reorganização do grid para empilhamento em coluna única em telas menores.
- **Variáveis CSS:** Gerenciamento da paleta de cores exigida (Preto `#121212`, Off White `#fff3ef`, Cinza `#b4aaa3`) e tipografia (Poppins).
- **Boas Práticas:** Uso de `gap` para espaçamentos internos do grid, atributos `alt` em todas as imagens para acessibilidade e efeitos de transição (`hover`) com `transform` e `transition` suaves nos elementos interativos.
- **Zero Frameworks:** Código desenvolvido do zero, sem Bootstrap, Tailwind ou afins.
